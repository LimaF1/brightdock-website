# BrightDock Digital Studio

**Build. Launch. Grow.**

A responsive, single-page website for BrightDock Digital Studio.

## Services
- Websites and landing pages
- Website audits and fixes
- SEO and copywriting
- Telegram bots and simple automation

## Local preview
Open `index.html` in a browser.

## Contact form
The enquiry form prepares an email in the visitor's email application. It does not store or transmit form submissions to a server.

## Publishing
This repository is prepared for GitHub Pages. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
